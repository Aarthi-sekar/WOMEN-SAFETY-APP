# 🚨 Women Safety Application – Shake to Send SOS

This Android application is designed to enhance women's safety during emergency situations.  
By simply **shaking the phone**, the app automatically sends an **SOS alert message** along with the **live GPS location** to pre-saved emergency contacts.

---

## 🔒 Features

### ✅ Shake Detection  
Automatically detects phone shaking using the accelerometer sensor.

### ✅ Automatic SOS Message  
Sends an SMS with:
- Custom emergency text  
- User’s **current GPS location**  
- Google Maps link for quick tracking  

### ✅ Live Location  
Fetches accurate latitude & longitude using Location Services.

### ✅ Add Emergency Contacts  
User can store multiple emergency contacts inside the app.

### ✅ Simple User Interface  
Easy to navigate & lightweight.

---

## 📱 How It Works

1. User opens the app and adds emergency contacts.  
2. Phone is shaken vigorously.  
3. App automatically:
   - Detects shake  
   - Fetches GPS location  
   - Sends SOS SMS to contacts  
4. Contacts receive:
   - Alert message  
   - Location map link
